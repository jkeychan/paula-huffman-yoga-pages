Adding a Class or Event

Your website's Schedule page shows whatever is on your Google Calendar automatically. Add it here, and it shows up there.

1

Open your calendar and create a new event

2

Fill in the title, date, and details

3

Save — it appears on the site within a few minutes

1

Go to your calendar

Open calendar.google.com and make sure you're signed in as paulashuffman@gmail.com — that's the calendar connected to your website. If you have more than one Google account, check the little picture in the top-right corner first.

2

Start a new event

Click the + Create button near the top-left, then choose Event.

3

Give it a title

Type the class or event name where it says Add title — for example, "Stretch Strengthen Restore" or "Yoga & Meditation Beach Retreat." This is exactly what visitors will see on your Schedule page.

4

Set the date and time

For a single class, set the start and end time as usual. For a multi-day retreat, turn on All day and set a start date and an end date — the site will show the full range.

5

Add the details

Click Add description and type anything visitors need: the Zoom link, price, what to bring, or sign-up instructions. Everything you type here shows up under the event on the site.

Location Fill this in for in-person classes — it's a nice touch, even though the site doesn't display it directly yet.
6

Save it

Click Save. That's the whole process — nothing else to publish or upload. Google usually refreshes the site's calendar view within a few minutes, sometimes up to an hour.

Good to know

  • Weekly classes: when creating the event, change "Does not repeat" to "Weekly" so you only have to set it up once, not every week.
  • Editing an event: click on it in the calendar, then the pencil icon. Changes appear on the site the same way new events do.
  • Cancelling something: open the event and click the trash icon. It disappears from the site once it's deleted.
  • Nothing showing up? Give it 10–15 minutes, then refresh the website. If it still isn't there, double-check you added it to the right Google account.
